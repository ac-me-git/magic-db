Import and export

Both are on the Collection page.

Export

FormatWhat is in itUse it for
CSVOne row per entry of the collection: card name, set, collector number, Scryfall ID, quantity, finish, condition, language, location, notes, price paid, date addedSpreadsheets, other tools, a copy you can read without AMTG
JSONEverything: every entry, every location (also the empty ones, with notes and order) and every deckA complete copy to bring back later, or to move to another installation

A single deck can also be downloaded as a text list from its page.

Import

Importing is two steps. First AMTG reads the file and shows what it understood — nothing is written. Then, if you confirm, it saves a backup and imports.

On the preview page you choose:

  • the location for the rows that do not name one (an existing one, or a new one);
  • the condition and language for the rows that do not give them;
  • whether to add to what you already have, or to replace it.

Rows that cannot be imported are listed with the reason, and can be downloaded as a CSV to fix and import again. They never stop the other rows. Importing the same file twice adds the cards twice. The collection must be unlocked.

The Moxfield and ManaBox formats follow those tools' documented column names and have not been tried on real files yet. If one of yours is not read correctly, please open an issue with a few rows of it.

How a row finds its card

In this order, stopping at the first that works:

  1. the Scryfall ID;
  2. set code and collector number;
  3. card name and set code;
  4. card name and set name;
  5. card name alone — only if the card has a single printing.

A name that matches several printings with nothing to tell them apart is ambiguous and is not imported. If the set is known but has several versions of the card (showcase, borderless) and the file gives no number, the regular one is taken and the row is counted as guessed.

Conditions

AMTG uses the Cardmarket scale: MT Mint, NM Near Mint, EX Excellent, GD Good, LP Light Played, PL Played, PO Poor. Files from tools that use the US scale are translated:

US scalebecomes
MintMT
Near MintNM
Lightly PlayedEX
Moderately PlayedGD
Heavily PlayedPL
DamagedPO

LP means something different in the two scales, which is why the translation depends on where the file comes from. An unknown condition makes the row fail; it is never guessed.

File details

UTF-8 (with or without BOM) and Windows-1252 are read; fields can be separated by commas, semicolons or tabs; files up to 20 MB.
